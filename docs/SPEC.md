完成项目：

> **黑洞周围天体运动与光传播的交互式三维实验室**  
> 在固定广义相对论背景中，模拟测试天体、光线与带电粒子的运动，提供三维轨迹演示和观察者成像，并预留接入守恒量验证与研究 Agent的接口（这个Agent还没做完，接口长啥样也还没做，先预留便于接入的口子）。

**主要成果是一款 Windows 桌面软件，名称为Black Hole Simulator.exe，能够双击启动、交互操作和演示；数学研究功能作为与可视化共用计算核心的扩展。** 以下内容可以直接作为开发任务说明书的初稿。

---

**1. 项目目标：让用户能够“设置一个黑洞实验，然后看见结果”。**

软件应支持这样的完整操作：

> 选择黑洞 → 设置参数 → 放置天体或光源 → 设置初速度或发射方向 → 开始模拟 → 调整观察位置 → 查看轨迹或图像 → 保存实验。

具体目标分为三类：

| 目标 | 具体要求 |
|---|---|
| **交互与演示** | 三维空间可以旋转、缩放；能够放置测试天体、发射光线、播放和暂停模拟 |
| **物理与数学** | 运动来自明确的相对论方程；注明近似和坐标选择；提供误差检查 |
| **研究与复现（预留）** | 导入候选守恒量，比较扰动前后结果，批量计算并保存参数与数据 |

成功标准不是画面复杂，而是：**用户能清楚地控制一个实验，看到可信的结果，并解释结果为何出现。**

---

**2. 物理范围：固定背景、测试物体和测试电磁场。**

整个项目首先采用以下假设：

- 黑洞背景预先给定，不随测试物体运动改变。
- 小天体近似为无自旋测试粒子，忽略其大小、潮汐形变和引力反作用。
- 多个测试天体可以同时显示，但彼此不产生引力。
- 初期光传播采用真空几何光学近似。
- 带电粒子受到背景引力和指定电磁场作用，忽略辐射反作用。
- 后续即使加入 Maxwell 波动模块，也先忽略电磁场对时空的反作用。

因此，初期可以模拟“许多小天体绕同一个黑洞运动”，但不能称为相互作用的相对论多体系统。

| 项目范围内 | 后续独立研究或暂不包含 |
|---|---|
| 黑洞附近测试天体的绕转、逃逸与捕获 | 双黑洞自洽运动与并合 |
| 光线弯曲、引力透镜、黑洞阴影 | 动态 Einstein 方程与引力波生成 |
| 背景电磁场中的带电粒子 | 等离子体集体效应、磁流体吸积 |
| 光的偏振平行移动 | 完整的发射、吸收、散射与偏振转移模型 |
| 简化背景下的电磁波传播 | 任意三维场景中的实时全波电磁模拟 |

软件中的“小恒星”最初只是有外观的测试粒子；它的球形模型不代表已经计算了恒星内部结构。

**3. 产品形态：两个主要视图，一个研究面板。**

| 界面区域 | 内容与操作 |
|---|---|
| **场景设置栏** | 背景类型、黑洞质量、自旋、电荷、天体和光源列表 |
| **三维轨迹视图** | 黑洞、天体、轨迹、光束、坐标参考；支持自由观察 |

两种主要视图承担不同任务：

- **三维轨迹视图**展示选定坐标下的路径，帮助理解运动。
- **观察者相机视图**通过光线追踪生成画面，回答“这个观察者会看见什么”。

必须在界面中标明坐标时间、固有时间或仿射参数的区别。多个对象一起播放时，需要统一播放规则，不能把各自固有时间直接当成同一个时钟。

**5. 数学计算核心：统一采用明确的状态和方程。**

对于中性测试粒子和光线，使用
\[
H(x,p)=\frac12g^{\mu\nu}(x)p_\mu p_\nu,
\]
以及 Hamilton 方程
\[
\dot x^\mu=\frac{\partial H}{\partial p_\mu},
\qquad
\dot p_\mu=-\frac{\partial H}{\partial x^\mu}.
\]

在 \((-+++)\) 号差约定下：

- 有质量测试粒子满足 \(2H=-m^2\)；
- 光线满足 \(H=0\)。

带电粒子使用
\[
H_q(x,p)
=
\frac12g^{\mu\nu}
(p_\mu-qA_\mu)(p_\nu-qA_\nu).
\]

开发时必须固定并记录以下约定：

| 项目 | 设计要求 |
|---|---|
| **单位** | 内部优先使用几何单位；界面允许按中心黑洞质量换算长度和时间 |
| **动量定义** | 明确正则动量与机械动量的区别 |
| **初始条件** | 优先让用户输入局部观察者测得的速度、方向，由程序转换为坐标分量 |
| **物理限制** | 有质量粒子的局部速度小于光速；光线自动满足零向量条件 |
| **事件处理** | 进入指定内边界、逃离计算区域、达到时长或计算失败时停止并记录原因 |
| **坐标选择** | 视界附近使用适当坐标或终止规则，避免把坐标奇性当成物理现象 |

**图形界面中的“拖动速度箭头”必须对应一个明确局部标架中的速度。** 不能把屏幕上的欧氏向量直接当成广义相对论初速度。

**6. 图形与成像：先保证解释清楚，再提高画面质量。**

三维场景首先包含：

- 中心黑洞及视界参考表面；
- 可选的能层、坐标轴和参考平面；
- 测试天体、速度箭头、轨迹尾迹；
- 光线及发射方向；
- 观察者的位置、朝向和视场。

这些表面和轨迹是坐标表示，应在说明中注明；它们不等于空间的等距嵌入。

观察者成像按下面的计算顺序实现：

1. 设置观察者的位置、四速度和局部正交标架。
2. 将屏幕像素对应为观察者局部天空中的方向。
3. 构造光子初始动量，并反向追踪零测地线。
4. 判断光线到达背景天球、穿过发光区域，还是进入黑洞。
5. 根据光源模型生成像素颜色。
6. 后续加入频移、强度变化和偏振显示。

**黑洞阴影需要通过光线命运计算出来，不能直接用一个黑色圆盘替代。**

为了兼顾交互体验，可以采用：

- 使用WASD和滚轮进行观察者的位置变换和视角缩放
- 操作相机时使用低分辨率预览；
- 停止操作后逐步提高图像质量；
- 轨道与光线结果缓存；

**7. 与 Killing 张量研究的连接：让画面对应可检验的结论（这一段预留接口，先不用做）。**

研究面板首先支持
\[
Q(x,p)=K^{\mu\nu}(x)p_\mu p_\nu.
\]

| 研究功能 | 输出 |
|---|---|
| 导入候选 \(Q\) | 公式、适用度量与参数 |
| 检查 \(\{Q,H\}\) | 精确为零、非零残差或未能判定 |
| 沿轨道监测 \(Q\) | \(Q(\tau)\) 与漂移曲线 |
| 比较原背景和扰动背景 | 并排轨道及对应物理量 |
| 比较不同修正阶数 | \(Q_0\)、\(Q_0+\varepsilon Q_1\) 的漂移 |
| 改变积分精度 | 判断漂移是否主要来自数值误差 |
| 批量改变初始条件 | 寻找异常场景与反例 |


这里要明确三个不同结论：

- 符号恒等式验证通过，可以确认相应守恒关系。
- 数值轨道上出现显著漂移，可以帮助定位错误或否定候选。
- 有限条轨道上近似不变，不能单独证明存在 Killing 张量。

**8. 软件结构：计算、显示和 Agent 共用接口。**

建议分成六个部分：

| 部分 | 负责内容 |
|---|---|
| **背景模型** | 度量、逆度量、导数、电磁势、坐标转换、定义域 |
| **运动求解** | 初始条件转换、积分、事件检测、数值诊断 |
| **光传播与成像** | 光线追踪、观察者标架、频移、偏振 |
| **可视化与交互** | 三维显示、相机、控件、图表和播放 |
| **研究与 Agent 接口（预留）** | 候选量验证、批量实验、参数扫描、结果查询 |
| **实验与文件管理** | 保存、加载、版本、导出与错误记录 |

关键设计原则是：

> **图形界面调用计算接口，Agent 也调用同一套接口（预留）。**

这样 Agent 能自动设置实验、运行计算和检查输出，不需要模拟鼠标点击。桌面软件也可以在没有模型 API 或网络连接时使用基础模拟功能。

**9. 开发流程：每个阶段交付一个能运行的结果。**

以下按约十二周设计；实际进度以验收结果调整。

| 阶段 | 工作内容 | 阶段验收 |
|---|---|---|
| **确定规范** | 固定单位、号差、坐标、对象类型和保存格式；搭建三维场景 | 能旋转缩放、设置参数、保存场景 |
| **Schwarzschild 轨道** | 实现初始条件构造、类时测地线、事件处理和轨迹播放 | 圆轨道、进动、逃逸、捕获预设可重复运行 |
| **Kerr 与数值检查** | 加入旋转黑洞、一般倾角轨道、守恒量监测 | 已知守恒量误差随精度提高而下降 |
| **光束演示** | 实现零测地线、单束和多束光线 | 平直基准、光线偏折与捕获演示通过 |
| **观察者成像** | 实现背景天球、像素反向追踪、低清预览与高清输出 | 可移动相机，生成合理的阴影和透镜图像 |
| **研究功能** | 导入候选量，加入扰动比较、批量运行和 Agent 接口 | 完成一次从候选量到验证报告的完整实验 |
| **整理交付** | 优化交互、处理错误、制作预设、测试 Windows 打包 | 在目标电脑上完成启动、操作、保存和导出演示 |


每个阶段内部都遵循：

**定义场景 → 推导或核实方程 → 实现计算 → 验证 → 接入图形 → 保存预设。**
